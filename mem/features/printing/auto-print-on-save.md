---
name: Auto-print on save
description: POS-style sticky toast prompt to print after invoice/payment save, with global + per-doc toggles
type: feature
---
After saving a new (non-draft) invoice or an individual recovery/payment, a sticky sonner toast appears with a Print action that opens the print dialog using the per-doc paper size from Settings → Printing.

Gated by two-level localStorage flags (`shamshad.autoPrint.v1`):
- `enabled` (global master) — when OFF nothing auto-prints
- `perDoc.invoice`, `perDoc.paymentReceipt` — independent toggles, only effective when master is ON

Defaults: all ON. Scope: new invoices + individual recoveries (Recovery page + QuickRecoveryDialog). City recovery bulk entries do NOT trigger per-entry prompts. Helpers: `shouldAutoPrint()` and `promptAutoPrint()` in `src/utils/autoPrint.ts`. Payment receipt HTML generated by `generatePaymentReceiptHTML()` in `src/utils/printUtils.ts`.
